# IT Helpdesk Lab (Home Project)

## Overview
Built a virtual IT helpdesk environment using Ubuntu Linux to simulate real-world troubleshooting scenarios.

## What I Practiced
- Network troubleshooting (IP, gateway, DNS)
- Internet connectivity testing (ping, traceroute, curl)
- System administration basics (Linux terminal)
- Incident simulation and ticket documentation

## Tools Used
- Ubuntu Server (VirtualBox)
- Linux networking tools (ip, ping, traceroute, curl)
- Terminal-based troubleshooting

## Example Scenarios
- User cannot access internet
- DNS resolution testing
- Website connectivity validation

## Key Skills Demonstrated
- IT support troubleshooting workflow
- Network diagnostics
- Problem isolation
- Technical documentation

## Status
Ongoing learning project (expanding into Windows Server + Active Directory next)
